About

What this is

WeatherPack answers one question before a trip: what does the sky look like where you're going, and what should you bring for it. Type in a destination and it pulls the live forecast, then turns that into a packing list based on the conditions and what you're actually doing there , sightseeing, a meeting, or something outdoors.

Weather data comes from the OpenWeatherMap API through a small FastAPI backend. The interface in front of it is plain HTML, CSS, and JavaScript no framework, built to stay fast and easy to read.

Built by Sboniso Vilakazi, a developer who likes shipping small tools that are actually useful on a given day.
